二、操作系统选择

方案A：Windows Server 2022 Standard 推荐

价格约 5,000 元（OEM正版授权，绑定一台服务器，终身有效）
优点专门为7×24小时运行设计，稳定性最高；无自动更新打断；无广告/弹窗；支持更大的文件句柄数；后台服务优化好
缺点价格较高；操作界面偏专业（和Win10类似，不难用）
适用正式交付客户、需要长期稳定运行的场景

方案B：Windows 11 专业版 预算友好

价格约 1,500 元（正版授权）/ 或免费使用（不激活，右下角有水印，功能完全正常）
优点价格低（甚至免费）；操作界面熟悉；功能完整
缺点可能自动更新重启（需手动关闭）；有系统广告；非专为服务器优化
适用内部测试、预算有限、对稳定性要求不那么极致

方案C：Windows 10 专业版 不推荐

价格约 1,000 元（正版）/ 或免费使用
缺点2025年10月已停止官方支持，不再接收安全更新；文件句柄默认值较低
结论不建议用于新部署

方案D：Linux (Ubuntu Server) 暂不支持

结论当前程序用 PyInstaller 打包为 Windows exe，不兼容 Linux。如需 Linux 支持需要重新开发。

三、配置说明（为什么选这些）

3.1 CPU：i5-13400（10核16线程）

采集是网络IO密集型（等待PLC响应），不是计算密集型。1000台Modbus TCP连接对CPU压力很小，4核就够。选i5-13400是因为：

  • 10核16线程，未来扩展有余量（2000台也能跑）
  • 65W低功耗，散热简单，电费省
  • 自带核显，不需要独立显卡
  • 当前市场价~1100元，性价比极高

3.2 内存：32GB（16G×2）

  • 操作系统预留：~2GB
  • 1000台设备Worker对象：~2GB
  • 1000个SQLite连接+WAL：~3GB
  • Python运行时+Flask+Waitress：~1GB
  • 实际占用约8GB，32GB有3倍余量

3.3 硬盘：1TB NVMe SSD

  • 1000台设备每10秒写一条数据 ≈ 260GB/月
  • 1TB ≈ 3个月数据，足够
  • NVMe 读写7000MB/s，远超实际需求（~400KB/s）
  • 三星980 PRO 1TB当前~550元，质保5年
💡 数据存储建议：如果风机运行数据需要长期保存（超过3个月），可额外加一块 2TB 机械硬盘做定期备份，约 400 元。

六、部署步骤

  1. 组装/购买服务器硬件
  2. 安装操作系统（Windows Server 2022 或 Windows 11 专业版）
  3. 安装网卡、芯片组驱动
  4. 设置固定IP地址（如 192.168.0.200），不要用DHCP
  5. 关闭Windows自动更新（防止半夜重启）
  6. 右键"系统调优.bat" → 以管理员身份运行 → 重启电脑
  7. 将 dist 文件夹复制到 D 盘（不要放 C 盘）
  8. 双击 start.bat 启动系统
  9. 浏览器访问 http://服务器IP:5000

七、网络连接说明

每台风机上的滤油机监测设备通过网线连接到塔底的光电转换器，将电信号转为光信号后通过单模光纤传输到中控机房。机房侧的光电转换器将光信号转回电信号，通过网线接入核心交换机，最终连接到监测服务器。

  • 每台风机独立IP地址（如 192.168.0.150~192.168.0.xxx）
  • 通信协议：Modbus TCP，端口3000
  • 采集间隔：10秒/次
  • 服务器端口：5000（Web管理界面）
